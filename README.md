# BigFileScan 大型文件检测工具

📌 项目简介

BigFileScan 是一款现代化、轻量级的 Python 文件扫描实用工具。工具不会执行未经许可的全盘扫描，扫描范围完全交由用户自主指定路径。扫描结束后可视化展示文件名、文件大小、完整路径、文件修改时间，同时支持自由配置最小、最大文件尺寸（MB）作为过滤条件，帮助你快速定位占用存储空间较大的文件，高效完成磁盘空间梳理。

✨ 功能清单

- ✅ 自定义扫描路径：仅扫描用户主动选择的目录，无后台全盘检索，保护隐私
- ✅ 完整文件元数据展示
  - 文件名称
  - 文件大小（自动换算为 MB）
  - 文件绝对路径
  - 文件修改时间（本地标准时间格式）
- ✅ 尺寸区间高级过滤：可独立设置最小值、最大值（MB），只输出符合大小区间的文件
- ✅ 递归子目录扫描：自动遍历所选路径下全部嵌套文件夹
- ✅ 优雅终端 UI：现代化控制台输出，带色彩标识、表格化排版，阅读体验更好
- ✅ 异常友好处理：权限不足、符号链接、无法访问目录自动跳过并静默记录，不会直接崩溃退出
- ✅ 零重型依赖：仅使用 Python 标准库，无需安装第三方包即可运行

🛠 使用方式

1. 准备 Python 3.8 或更高版本运行环境
2. 下载本项目源码压缩包并解压到本地
3. 在终端进入项目文件夹，执行：
   python BigFileScan.py
4. 根据交互式指引依次填写：
   - 需要扫描的目标文件夹路径
   - 文件筛选最小尺寸（MB）
   - 文件筛选最大尺寸（MB）
5. 等待扫描完成，查看格式化的文件清单

⚠️ 安全说明

- 程序仅读取文件元信息，不会修改、移动、重命名或删除任何磁盘文件；
- 遇到无读取权限的目录、系统受保护文件会自动跳过；
- 所有扫描操作仅在用户选定路径内执行，不会私自扩大检索范围。
